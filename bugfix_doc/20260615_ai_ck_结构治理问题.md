## 一、业务上下文(整改的依据)

`shucang_market` 是休闲益智手游(方块/麻将/数独，如 `com.kcolb.juggle`、`com.nebula.mahjongtile`、`com.kcolbpuzzle.us.ios`、`com.mathbrain.sudoku`)买量投放的 CK OLAP 报表库，服务 MI ROI360 看板 + PGP 点位平台。

核心链路 = 最常用 SQL 形态：

```
点位映射(s2s_event→campaign) → 消耗 spend → 回收 revenue(SDK默认/AF对照) → 留存 cohort
   → ROI/LTV(应用层按 date_diff 拼装 + correction 纠偏) → 预测 forecast v6
```

主键维度恒为 `bundle_id × media_source × campaign/adset/ad × country × active_date/date_diff`。

## 二、生产真实使用(nexus ROI360 路由 = ground truth)

来源 `nexus/.../roi/ua/{spend,revenue,retention,correction,convert-type}.go`：

| 角色 | 默认表 | 连接 |
|---|---|---|
| 消耗 | `tj_ad_spend_active_v2_view`(v3 路径=`tj_ad_spend_active_v3`) | `selectDB(ROI360)=aliyunDB` |
| 回收 | `tj_ad_revenue_v2_view`(AF)/`tj_ad_sdk_revenue_view`(SDK)/v3=`tj_ad_revenue_v3` | aliyunDB |
| 留存 | `af_cohort_user_acquisition_v2_view` | aliyunDB |
