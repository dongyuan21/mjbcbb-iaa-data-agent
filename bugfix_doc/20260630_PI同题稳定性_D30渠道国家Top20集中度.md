## 根因拆解

```text
同一问题
  ├─ Agent 路径 A（002452）：activation 表 smoke → 渠道×国家聚合 → 拿到 rows → 继续迭代 → 出报告
  ├─ Agent 路径 B（002494-1）：只读知识/文件 → 6 次无 SQL 证据 → no_progress_tools
  └─ Agent 路径 C（002494-2）：错表 device_camp_dau_behavior → SELECT* / PII / execution → consecutive_tool_failures
```

相关 runtime 逻辑：`runtime/backend/app/services/pi_agent.py` `_update_tool_progress_state()`

- `consecutive_failures >= 3` → `consecutive_tool_failures`
- `consecutive_no_progress >= 6` → `no_progress_tools`

guardrail 对用户一致：`runtime/backend/app/services/executors.py` / `runtime/tools/data_query.py`

## 验收标准

1. **Replay PASS**：`python3 tools/scripts/pi_replay_regression.py --case PI_D30_ARPU_TOP20_CHANNEL_COUNTRY_CONCENTRATION` 连续 2 次成功。
2. **跨用户稳定**：同一 case 用 `--session-user 002452` 与 `--session-user 002494`（或 codex-reviewer 两次独立 session）均 PASS。
3. **禁止错表**：query_records 不得出现仅依赖 `ads_market_device_camp_dau_behavior_di` 作为 D30 回收唯一来源。
4. **PII**：无 `pii_blocked` / 无最终投影 `distinct_id`。
5. **答案要素**：必须含 `Top 20%`、`渠道`、`国家`、`D30`、`占比/比例`；须标注 cohort 窗口与 freshness。
