## 材料状态标识

showoff 不提供实时运行结论。材料中的能力说明按下列标签标识；判断当前可用性时，应读取对应证据。

| 标签 | 它说明什么 | 需要什么证据 |
|---|---|---|
| **当前代码** | 代码库已存在相应实现 | 当前源码、组件测试或静态门禁 |
| **主链已接** | 真实 API / SSE / Worker 入口会经过该实现 | 入口调用链与端到端执行证据 |
| **环境已验证** | 指定环境在指定版本、配置下实际通过 | 本次部署、健康检查、真实请求和可追溯 trace |
| **历史快照** | 保留过去的设计、发布或测量记录 | 归档日期与原始上下文；不能替代当前结论 |

没有标签或证据的“已完成”“线上可用”不应进入 showoff。代码默认值也不能替代某个 Test 或 Production 环境的实时配置。

## 展示边界

- 只展示架构、能力、流程和匿名业务场景。
- 不展示凭证、用户级明细、设备 ID、IP、广告账户操作人。
- 不把原始材料、草稿、截图抽取或旧快照当作已验证事实。
- 只读分析：解释、拆解、校验、提示风险；不表达自动停投、放量、改预算。
