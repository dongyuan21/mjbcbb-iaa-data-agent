# Showoff 汇报材料

本目录用于对外展示 Data Agent 数据基座。读者可以是业务、DA、数仓、投放或管理同学；目标不是解释每个脚本和字段，而是讲清楚三件事：

1. 这个系统解决什么问题。
2. 当前已经具备哪些能力。
3. 哪些事情仍需要人工决策或继续建设。

## 推荐阅读顺序

| 顺序 | 文件 | 适合场景 |
|---|---|---|
| 0 | `文风规范.md` | 维护入口，新增或重写 showoff 材料前先看 |
| 1 | `data_agent_showoff.html` | 快速演示，适合会议投屏 |
| 2 | `DataAgent数据基座汇报稿.md` | 主汇报稿，说明基座价值、分层能力和下一步路线 |
| 3 | `当前系统架构图.md` | 架构附录，说明系统如何从数据源走到 Agent 输出 |
| 4 | `ai_hive与ai_ck关系及语义层接入总览.md` | 总览附录，说明 MC 与 CK 两套数据知识如何一起服务语义层 |
| 5 | `ai_hive建设思路与语义层关系.md` | 专题附录，说明 MaxCompute / Hive 表知识库怎么建设 |
| 6 | `ai_ck建设思路与语义层关系.md` | 专题附录，说明 ClickHouse / MI 报表知识库怎么建设 |
| 7 | `Agent知识按需加载与上下文预算.md` | 专题附录，说明知识库持续变大时单次问答成本如何受控 |

## 统一表达口径

| 对外说法 | 内部对应 |
|---|---|
| 数据目录和查数说明 | `ai_hive/`、`ai_ck/` 表卡、catalog、profile |
| 业务口径合同 | `knowledge/agent_knowledge/semantic_contract/` 的实体、维度、指标、join、状态机 |
| 可复用分析资产 | `da_assets/` 的已验证 SQL、分析流程、复盘案例 |
| 业务规则和边界 | `knowledge/` 的 policy、protocol、阈值说明 |
| 质量保障 | `tools/` 和 `eval/` 的数据新鲜度、质量检查、回归验证 |

## 展示边界

- 只展示架构、能力、流程、聚合状态和匿名业务场景。
- 不展示数据库密码、AK/SK、Token、Cookie、SSO ticket、用户级明细、设备 ID、IP、广告账户操作人。
- 不把原始材料、草稿、截图抽取或旧快照当作已验证事实。
- 当前定位是只读分析基座：能解释、拆解、校验和提示风险；不表达自动停投、放量、降预算等自动动作能力。
