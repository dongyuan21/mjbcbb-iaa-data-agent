## 漏斗全景

投放漏斗可以按以下层级理解：

```text
Impression -> Click -> Install -> Activation/Engagement -> Revenue
```

对应指标：

| 层级 | 指标 | 公式 | 主要用途 |
|---|---|---|---|
| 曝光 | CPM | cost / impressions × 1000 | 出价水平、库存价格 |
| 点击 | CTR | clicks / impressions | 创意吸引力 |
| 点击成本 | CPC | cost / clicks | 点击成本 |
| 转化 | CVR | conversions / clicks | 商店/落地转化效率 |
| 安装效率 | IPM | installs / impressions × 1000 | 新素材冷启时更早判断素材质量 |
| 安装成本 | CPI | cost / installs | 获客成本，ROI360 分母 |
| 行为成本 | CPA / CPE | cost / target events | oCPX / engagement 优化目标 |
| 变现 | ROAS | ad revenue / ad cost | 回收率 |
| 长期价值 | LTV | cohort 累计变现 / cohort 安装数 | 用户价值 |
| 最终业务指标 | ROI360 | LTV360 / CPI | 长期回收能力 |

## 常见混淆

### ROAS vs ROI

严格定义：

```text
ROAS = Revenue / Cost
ROI = (Revenue - Cost) / Cost
```

公司日常可能混用 ROI / ROAS；agent 输出时应优先写清公式，避免只说“ROI”。

### IPM vs CPI

```text
IPM = installs / impressions × 1000
CPI = cost / installs
```

含义：

- IPM 更偏创意质量和早期转化效率。
- CPI 是出价、素材、渠道、商店转化共同作用后的成本结果。

### CPM vs eCPM

| 指标 | 视角 |
|---|---|
| CPM | 广告主出价端，每千次曝光花多少钱 |
| eCPM | 发行商变现端，每千次曝光赚多少钱 |

BB 既是广告主也是发行商，agent 回答时必须先判断问题问的是投放端还是变现端。

## 待审核点

1. PM/业务口径是否默认以 `af_cpi` 还是 `media_cpi` 做 CPI。
2. ROI/ROAS 在输出给不同角色时是否要统一显示为百分比。
3. `Imp/DAU`、`AdARPDAU`、`eCPM` 是否进入当前 data agent 第一阶段。
