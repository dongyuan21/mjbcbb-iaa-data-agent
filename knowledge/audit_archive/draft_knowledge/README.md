# draft_knowledge（本机草稿区）

本目录存放从个人 Obsidian / 外部笔记蒸馏来的**未审核草稿**，默认不入库。

## 规则

- 目录整体在 `.gitignore` 中；只版本化本 `README.md` 与 `INDEX.md`。
- Agent **不得**把本目录内容当 verified 事实；正式知识写入 `knowledge/agent_knowledge/`。
- 本机可继续放 `02_*.md` / `来源清单.md` 等草稿；晋升流程见 `knowledge/agent_knowledge/policies/默认召回边界与晋升规则.md`。

## 本机约定

来源 vault 用逻辑名 `local_obsidian_vault/8方块/...`，不要写本机绝对路径或个人目录名。
