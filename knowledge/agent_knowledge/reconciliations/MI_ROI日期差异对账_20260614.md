## CK 复算 SQL

```sql
WITH spend AS (
  SELECT
    sum(cost_zhe / nullIf(currency, 0)) AS total_cost_zhe,
    sum(registers) AS total_registers
  FROM shucang_market.tj_ad_spend_active_v2_view
  WHERE bundle_id = 'com.block.juggle'
    AND active_date BETWEEN '2026-05-01' AND '2026-05-07'
),
rev AS (
  SELECT
    sumIf(revenue, date_diff <= 6) AS revenue_le6,
    sumIf(revenue, date_diff <= 7) AS revenue_le7
  FROM shucang_market.tj_ad_sdk_revenue_view
  WHERE bundle_id = 'com.block.juggle'
    AND active_date BETWEEN '2026-05-01' AND '2026-05-07'
)
SELECT
  total_cost_zhe,
  total_registers,
  revenue_le6,
  revenue_le7,
  revenue_le6 / nullIf(total_cost_zhe, 0) * 100 AS roi_le6,
  revenue_le7 / nullIf(total_cost_zhe, 0) * 100 AS roi_le7
FROM spend
CROSS JOIN rev;
```

## 结论

MI 与 CK 对齐关系：

| MI 字段 | 业务展示 | CK 口径 |
|---|---|---|
| `roi_6` | ROI7 | `date_diff <= 6` |
| `roi_7` | ROI8 | `date_diff <= 7` |
| `revenue_6` | 7 日累计收入 | `date_diff <= 6` |

因此：

```text
ROI_N / LTV_N 的 N 是业务展示天数；
底层最大 date_diff = N - 1。
```

例子：

```text
ROI1  = date_diff <= 0
ROI7  = date_diff <= 6
ROI30 = date_diff <= 29
ROI360 = date_diff <= 359
```
