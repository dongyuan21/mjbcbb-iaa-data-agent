# 国家等级映射

> 状态：active  
> 创建日期：2026-06-19  
> 用途：SQL 写作、投放分析和素材 / campaign 分层分析中，将 T1 / T2 / T3 国家层级展开为稳定的 ISO 2 位 `country` 过滤条件。  
> 维护边界：这是项目内国家价值分层表；如果后续业务调整国家等级，以新确认版本覆盖本文，并同步 `knowledge/agent_knowledge/catalog.yaml`。

## 使用规则

- SQL 过滤使用 `country` 字段的 ISO 2 位代码，不使用 `country_cn`。
- 用户提到多个层级时取并集。
- 用户要求排除层级时，用该层级代码集合做 `NOT IN` 或改写为互补层级。
- 用户要求按国家层级分组时，使用 `CASE WHEN country IN (...) THEN 'T1' ... END AS country_tier`。
- 不从记忆里手写国家列表；以本文表格为准。
