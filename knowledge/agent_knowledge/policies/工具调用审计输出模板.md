# 工具调用审计输出模板（第一阶段）

> 适用场景：广告平台 API、MI API、MaxCompute / CK 查询、脚本工具等的单次调用。
> 约束：第一阶段不落数据库，仅产出可读文件/会话摘要即可。

## 1. 审计事件结构（必须字段）

每次调用需至少产出以下字段：

- `question`：本次触发调用的原始问题或目的
- `tool_used`：工具名（如 `mi_curl` / `maxcompute-dataworks` / `tool_name`）
- `parameters`：去敏后的入参（含版本、查询范围、分页参数、过滤条件）
- `result_summary`：统一摘要（success/failed、主要指标、关键命中）
- `conclusion`：本次调用可执行结论（`可继续` / `需重试` / `待补充` / `blocked`）
- `human_decision`：`待用户确认`、`已确认`、`已拒绝` 三选一；无决策时必须是 `待用户确认`

推荐附加字段：

- `run_id`：`工具名-时间戳-短随机串`
- `started_at`：ISO8601
- `latency_ms`：耗时毫秒
- `risk`：`info / warning / blocked`
- `next_action`：下一步动作建议（如 `重试一次` / `需要用户补充凭据`）
- `error_code` / `error_message` / `retry_hint`：调用失败时必填

## 2. 可直接复用 JSON 模板

```json
{
  "run_id": "mi_roi360_20260628_xxx",
  "question": "查询 bundle 的素材 ROI 报表",
  "tool_used": "mi_query_runner",
  "started_at": "2026-06-28T10:20:30+08:00",
  "latency_ms": 742,
  "parameters": {
    "report_type": "asset",
    "bundle_id": "com.xxx.app",
    "start_date": "2026-05-28",
    "end_date": "2026-06-27",
    "limit": 20
  },
  "result_summary": {
    "status": "success",
    "rows": 20,
    "summary_fields": ["roi0", "roi30", "ret7"],
    "notes": ["包含 google/meta/applovin 全平台返回"]
  },
  "conclusion": "可继续",
  "risk": "warning",
  "human_decision": "待用户确认",
  "next_action": "等待 UA 补充是否按 campaign 级下钻",
  "error_code": null,
  "error_message": null,
  "retry_hint": null
}
```

## 3. 与本项目的约束对应

- 不记录敏感凭据（Token、cookie、密钥）
- 仅保留最小去敏参数
- 不进行自动投放动作；只产出“可行动结论 + 人工决策”
- 与 `TODO/工具建设待办.md` 的 P1 工具调用审计项保持一致

## 4. 最小判定逻辑

- `status=success` 且 `conclusion=可继续`：可继续下游分析
- `status=failed` + `risk=blocked`：不继续推理，需用户输入
- `risk=warning`：允许继续，但需在下一次输出中说明不确定性
