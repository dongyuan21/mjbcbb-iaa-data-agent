# knowledge 一致性门禁

本文件说明 `knowledge/` 三层结构的维护入口。它不定义业务事实，只记录如何检查 manifest、状态边界和默认召回。

## 运行

```bash
python3 tools/scripts/check_knowledge_consistency.py
```

报告输出到 `eval/知识一致性报告.md`。

## 检查内容

- `agent_knowledge/catalog.yaml` 是否覆盖 `knowledge/` 下所有 `.md`、`.csv`、`.json`、`.yaml` 文件。
- manifest 中的 `status`、`default_recall`、`applies_to_current` 是否符合默认召回边界。
- Markdown 链接、prompt 依赖路径、JSON、CSV 是否可解析。
- `trial_active` 阈值表是否仍具备必要的来源和状态字段。
- `audit_archive/` 下的 draft / snapshot 是否没有被默认召回。

## 维护原则

- 新增可默认使用的业务规则，放入 `agent_knowledge/` 并登记 manifest。
- 草稿、快照、一次性分析先放入 `audit_archive/`，不得默认召回。
- 修改任何 knowledge 文件后，先更新 manifest，再跑门禁。
