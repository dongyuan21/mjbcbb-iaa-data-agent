# UA 决策行为沉淀

本目录集中存放 UA 决策行为沉淀相关的方案、任务书、阶段报告、台账与训练 run 产物。

`data_agent_plan/` 根目录只保留 Data Agent 路线图 / Runtime / 路由 / Text2SQL 等规划文档；UA 沉淀不再平铺在根下。

## 入口

| 用途 | 文件 |
|---|---|
| 权威方案 | `UA决策行为沉淀与回测方案.md` |
| 执行任务书 | `UA决策行为沉淀执行任务书.md` |
| 实施台账 | `UA决策行为沉淀实施台账.md`（§9 为 Phase3 v2+DiD 终态摘要） |
| 后续清单 | `UA沉淀后续工作清单.md`（预执行清单，进度以台账为准） |
| Phase3 当前评估 | `UA决策沉淀v2评估报告.md` + `UA决策操作分类体系设计.md` |
| Phase3 当前数据 | `../ua_phase3_v2_data/`（v2 双源样本与结果；v1 `ua_phase3_run/` 已删除） |

## 规则

1. 本目录材料默认是规划 / 阶段产物 / 证据，**不是** Agent 默认召回事实源。
2. 表卡 `source_docs` / `evidence` 可引用本目录合同与报告；改路径时同步表卡与台账。
3. 历史报告里若仍写 `ua_phase3_run/`，视为 v1 现场路径，已废弃；当前 run 产物看 `../ua_phase3_v2_data/`。
