## 0. 施工 agent 必读

### 0.1 三十秒建立世界观

这轮重构做一件事：**让「模型能看哪些知识」只由 Registry 说话，route 退化成建议菜单。**

读文件有三条通道，**不要以为只剩 Registry 一种**：

| 通道 | 归层 | 谁走 | 谁授权 | `candidate_sql` |
|---|---|---|---|---|
| ① slim prior 建议 | **L3** | Runtime 渲染 AssetRef 候选给模型 | Registry | 拒（永久） |
| ② 模型工具按需读 | **L3** | 模型主动调 5 个知识工具 | Registry + 全局 DENY | 拒（永久） |
| ③ bootstrap 确定性快路径 | **L4** | 服务端固定探针，不经模型发现 | 代码常量 + SHA 钉死 + 有界预算 | **可以**，须如实标注 |

> **通道 ③ 属 L4，不是 L3**（D20）。这一点很关键：它解释了为什么「面 B 拒 candidate_sql + 面 A 被删」**不等于** candidate_sql 永远不能加载。详见 §3.1。

被删掉的是**第四种**——历史上叫「面 A / 肥喂」：route yaml 的 `first_read` 当钥匙、按目录前缀把正文直接塞进 prompt。它不在上表里，因为它要消失。

术语对照（历史讨论里出现过，代码里没有这两个名字）：
- **面 A** = `KnowledgeRouter._is_asset_allowed` + `build_knowledge_context_parts` 那条 route-scoped 送货链
- **面 B** = `ExplorationAssetRegistry` + `knowledge_tools._authorize` 那条 registry-scoped 链

### 3.1 三条通道的正确归层（D20 修正 D16）

| 通道 | 归层 | 门 | `candidate_sql` |
|---|---|---|---|
| ① slim prior 建议 | **L3** | Registry | **拒**（永久） |
| ② 模型工具按需读 | **L3** | Registry + 全局 DENY | **拒**（永久） |
| ③ bootstrap 确定性快路径 | **L4** | 代码常量 + SHA 钉死 + 有界预算 | **可以**，须如实标注 `asset_status` |

**为什么 L4 可以而 L3 不可以** —— 两层治理的是不同的东西：

- **L3 管「模型能看什么」**。`candidate_sql` 是未晋升草案，让模型把它当可信知识检索/阅读，就是 D17 要防的「未验证 SQL 被当成 verified 证据」。**所以 L3 永久拒，这是对的，不要动 `DENY_PATTERNS`。**
- **L4 管「服务端自己去取什么」**。bootstrap 是服务端固定探针：路径写死在代码常量里，模型不能选、不能发现、不能改。它读一份未晋升 SQL 并**在证据里标明 `asset_status: candidate_sql/未验证`**，本质是「Runtime 说：我用一份草案跑了个有界查询，可信度如此」——这不是把草案伪装成可信知识，风险模型完全不同。

> 代码里原本就有这份诚实标注：`asset_status="candidate_sql/未验证"` 与 `"candidate_sql/已小窗口验证未晋升"`。2026-08-06 的 C 类清理把断言删了，但标注机制本身是对的设计。

**所以「candidate_sql 永远不能加载」是伪命题**，它有三个合法归宿：

1. **L4 快路径**（本层授权，不问 L3）—— 需要该能力时走这条
2. **晋升为 verified_sql** → 进 Registry → L3 ①② 可读（这 3 个资产 7 月就已晋升，见 R-13）
3. **退役** —— 本轮对那 4 条快路径的选择（D21）

第 3 条是**产品取舍，不是架构限制**。将来要恢复走 1 或 2 都是开着的门。

**L3 的写权边界**（精确表述，别写成「L3 完全只读」）：不写知识、不授权执行、不裁终态，**但持有自身预算/审计计量的写权**——[`knowledge_tools.py:287`](../../runtime/backend/app/services/knowledge_tools.py#L287) `_commit_read` → [`exploration_budget.py:254`](../../runtime/backend/app/services/exploration_budget.py#L254) `reserve` → `:230-239 UPDATE + db.commit()`。
