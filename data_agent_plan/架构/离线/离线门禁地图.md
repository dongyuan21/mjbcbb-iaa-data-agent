# 离线门禁地图

> 状态：`active` · 更新：2026-08-08
> 用途：回答「我改了 X，必须跑哪些检查」。细则仍在各脚本；本文件只做触发地图。
> 发布前总包：`python3 tools/scripts/verify.py`（偏运行时回归；**不替代**下表知识门禁）。

## 怎么用

1. 找到你改动的资产类型。
2. 跑「必跑」列；「建议」列在涉及默认召回 / 跨层时补上。
3. 硬错误必须清零；新鲜度阻塞 (freshness blocker) 只记录，不强行改绿。

## 按变更类型

| 你改了什么 | 必跑 | 建议 / 条件跑 | 权威说明 |
|---|---|---|---|
| **数仓表卡** `ai_hive/.../tables/*.yaml` | `check_table_card_quality.py`；重建数仓目录 (catalog) | 实时探测 (live probe) + 样例 SQL；影响默认选表时回归相关用例 | 数仓准入标准 · 表准入技能 (table-intake) |
| **分析库表卡** `ai_ck/.../tables/*.yaml` | `check_table_card_quality.py`；`rebuild_ai_ck_catalog.py`（或 `--check`） | 分析库探测；指标解释页相关再看指标层边界 | 分析库准入标准 · 表准入技能 |
| **隐私策略 (PII_POLICY) / 隐私字段** | 盖章流程 + `check_table_card_quality.py` | 相关表卡再扫一遍 | 各库隐私说明 |
| **knowledge/ 任意文件** | `check_knowledge_consistency.py`；同步 `knowledge/.../catalog.yaml` | `check_authority_map.py`（若动了事实切面） | AGENTS.md §11 |
| **权威映射 (authority_map.yaml)** | `check_authority_map.py` | 确认切面路径存在（原始件 raw 除外） | authority_map |
| **语义合同 (semantic_contract) 或分析库指标** | `check_metric_layer_boundary.py`；知识一致性 | 语义组合 / 回归 | 指标层边界 |
| **已验证/候选 SQL 或资产索引** | `check_sql_promotion.py`；`check_asset_status_consistency.py`（若动状态 status） | `check_asset_eval_integrity.py`；小窗口复跑 | SQL 晋升治理 |
| **分析标准流程 / 决策案例 / 报告策略** | 更新 `da_assets/index.yaml`；资产状态一致检查 | 注册表可解析 / 路由引用检查 | 文档入库技能 |
| **任务路由 / 检索映射** | `check_agent_retrieval_map.py`；`check_route_asset_resolvable.py` | 相关检索路由用例 | 任务路由治理 |
| **路由清单白名单** | `check_route_asset_resolvable.py` | 确认运行时有消费方（勿只绿门禁） | 架构层 L3 决策口径 |
| **新鲜度相关脚本/契约** | `check_freshness_health.py`（刷新后） | `refresh_freshness_pipeline.py` | 新鲜度运行手册 |
| **运行时后端代码** | `runtime/backend` pytest；必要时 `verify.py` | 智能体回归 (agent regression) | runtime/AGENTS.md |
| **多类同时改** | 按上表并集；最后 `verify.py` | 影响面大时 `check_knowledge_impact.py` | 数据底座维护分流 |

## 常用命令（仓库根）

```bash
# 表卡
python3 tools/scripts/check_table_card_quality.py
python3 tools/scripts/rebuild_ai_ck_catalog.py --check   # 分析库；写回去掉 --check

# 知识
python3 tools/scripts/check_knowledge_consistency.py
python3 tools/scripts/check_authority_map.py
python3 tools/scripts/check_metric_layer_boundary.py

# SQL / 资产状态
python3 tools/scripts/check_sql_promotion.py
python3 tools/scripts/check_asset_status_consistency.py

# 路由 / 注册表可解析
python3 tools/scripts/check_agent_retrieval_map.py
python3 tools/scripts/check_route_asset_resolvable.py

# 离线图导出（源图变更后）
bash tools/scripts/export_offline_diagrams.sh

# 发布前总包（含前端/后端/回归；实时数仓/分析库不在此包内强制）
python3 tools/scripts/verify.py
```

## 评测 E* 归位（离线侧）

| 评测层 | 主要评什么 | 离线建设什么 |
|---|---|---|
| E1 | 架构层 L2 问题理解 | 金标 / 固定用例 (fixture)；不替代表卡门禁 |
| E2 | 架构层 L3 路由 + 资产授权 | 注册表拒绝/可见性金标；与路由门禁互补 |
| E3+ | 选表/SQL/答案质量等 | 已验证 SQL、语义、回归用例 |

**晋级分母**只用人工/已验证金标；临时金标 (provisional) 不得粉饰为通过（见在线控制面评测说明）。

## 和「定时刷新」的边界

门禁地图 = **改完知识后的检查**。
新鲜度定时任务 = **状态探测**，不替代上表任一知识门禁。对照见 [`定时刷新与手工维护对照.md`](定时刷新与手工维护对照.md)。
