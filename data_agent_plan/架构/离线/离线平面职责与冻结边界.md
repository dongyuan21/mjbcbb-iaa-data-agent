## 裁决

离线平面回答：**可信知识与数据合同从哪里来、怎样抬信任、怎样变成运行时 (Runtime) 可消费。**

它不是微服务，也不替代各库技能 (skill) / 准入标准正文。本文件只冻结**责任边界**。

## 五类责任（逻辑层）

| 责任 | 做什么 | 不做什么 |
|---|---|---|
| **输入归档** | 保留来源、周期、提取方式；原始件 (raw) 可追溯 | 不把原始件当已验证 (verified) 事实 |
| **结构化沉淀** | 写成表卡 / 策略 (policy) / 标准流程 (SOP) / 候选 SQL (candidate_sql) 等对象 | 不靠猜测补关联 (join) / 阈值 / 官方口径 |
| **晋升与门禁** | 抬晋升状态 (promotion_status) / 文档状态 (documentation_status)；跑检查脚本 (check_*) | 不因「跑通过一次」自动已验证 (verified) |
| **注册与发布** | 目录 (catalog) / 索引 (index) / 注册表 (Registry) 可解析集合；部署同提交 (commit) | 不手改投影字段当第二真相源 |
| **状态刷新** | 新鲜度 (freshness)（及约定的健康检查）定时/按需探测 | 不刷新业务口径正文、不晋升资产 |

## 与在线交接

离线交给在线的窄口（见总图绿条）：

- 已验证 SQL (verified_sql)、已确认策略 (confirmed policy)、可查询表卡、注册表版本 (Registry revision)、路由**建议**菜单

不交：候选 SQL (candidate_sql)、原始件 (raw)、草稿 (draft)、待办 (TODO/)（第四层 (L4) 常量探针除外，且不进第三层 (L3) 知识面）。

## 人 vs 智能体 (Agent)

| 智能体可先做 | 必须人 / 负责人 (owner) 拍板 |
|---|---|
| 结构分层、表卡骨架、门禁串联、待办显性化 | 默认选表、跨表关联 (join)、隐私字段 (PII) 边界、红线阈值、官方口径 |
| 实时探测 (live probe)、小窗口验证记录、目录重建 | 高风险默认召回晋升、语义层晋升 |
| 报告抽取为草稿标准流程/案例 | 把已审阅 (reviewed) 升为默认事实 |

## 冻结禁令

1. 禁止在运行时主链里「跑通即写回」已验证 (verified) / 已确认 (confirmed)。
2. 禁止为离线方便新建第二套目录 (catalog) / 表卡正文。
3. 禁止把新鲜度快照 (freshness snapshot) 当未探测的当前事实。
4. 禁止定时任务改业务知识正文或自动晋升 SQL。
5. 禁止目录名替代状态字段（已验证目录 (verified_sql/) ≠ 字段已 verified）。
