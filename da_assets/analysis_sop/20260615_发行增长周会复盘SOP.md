# 0615 发行增长周会复盘 SOP

> 来源：`da_assets/raw/2026-06-15_发行增长周会_docx.md`
> 状态：`draft`。本文从 0615 周报正文、Word 表格和已复核图片抽取；用于指导后续周报/经营复盘，不是 verified SQL。

## 适用问题

用于回答和拆解：

- 本周发行增长周会相对上周 0610 的核心变化是什么。
- 哪些包体 / 端 ROI 达标、跌破红线、红线之上未达标、或需要继续观察。
- DNU / DAU 变化来自 UA、预装、ASA、Organic、国家结构、下架、管控还是回收约束。
- ROI 预估偏差、点位测试、素材冷启、自投 campaign、ADX、Push、风控核减和数据产品进展如何进入后续分析。
- 周报应该如何沉淀成可复用的 SOP、case、待补源数据和后续 SQL 验证任务。

## 标准拆解流程

1. **先确认周报口径**
   - 本周窗口：`2026-06-05` 到 `2026-06-11` 日均。
   - 上周窗口：`2026-05-29` 到 `2026-06-04` 日均。
   - 分析平台：报告称为加权平均。
   - 6 月实际 DAU / DNU：`2026-06-01` 到 `2026-06-11` 日均。
   - Organic：数仓 DAU / DNU 口径减去业务 AF 口径的 UA、预装、ASA。

2. **再做 ROI 分层**
   - 用 `weekly_roi_status_summary.csv` 输出 `above_target`、`between_redline_target`、`below_redline`、`missing_threshold`。
   - 报告内 `roi_target_thresholds_from_report.csv` 是 0615 周报证据；长期治理仍优先使用 confirmed / trial_active 阈值表。
   - 对破红线对象必须拆渠道和消耗占比，如 Demo Game 04 GP 的 Applovin、Demo Game 08 iOS 的 Liftoff / Applovin。

3. **拆 DNU / DAU 来源**
   - 先用 `weekly_dau_dnu_wow_summary.csv` 看总量，再看 UA、预装、ASA、Organic。
   - 对大盘类产品要单独看关键国家和关键市场，例如 Game Top 全量和美国。
   - 对预装异常要区分预算放开、降价、渠道屏蔽、P360 拦截、下架影响。

4. **抽 ROI 预估偏差**
   - 只引用正文明确 claim，如 moloco / applovin / liftoff / ASA 在 D7 到 D60 节点的高估或低估。
   - `image_048` 到 `image_053` 的密集矩阵需源电子表格，不逐格 OCR。
   - 输出时标 `forecast_bias_reviewed`，不得当作模型已修复事实。

5. **抽实验与系统进展**
   - 点位：点位逻辑、回传目标、当前样本、ROI1 / ROI7 / 分析平台、是否停止或待回收。
   - 素材：S 级爆款占比、冷启通过率、渠道拉低原因、平台能力进度。
   - 自投：按产品 / 端 / campaign 生命周期看预算、近 3 日 分析平台、是否达标、是否只观察。
   - ADX：导流 vs 信息流大盘，优先输出方向和因果分析需求。
   - Push：同时看 DAU、收入、总时长 / 游戏时长、ARPDAU、关闭率、holdout 兜底问题。
   - 风控：核减金额只作为预期排查结果；动作仍需技术沟通、协议和业务流程。

6. **生成待补数据**
   - 源电子表格：ROI 偏差矩阵、UA 绩效/绿线管控表。
   - MI / 分析平台 导出：点位 / campaign 看板截图对应明细。
   - SQL 验证：ROI、DNU、渠道消耗占比、Push / ADX 实验因果。
   - 人工拍板：ROI 下修 buffer、风控黄线、核减动作、放量/停投最终决策。

## 本次报告抽出的复用口径

| 主题 | 口径 / 规则 | 来源 |
|---|---|---|
| 周报写法 | 结果要展示数据结果；认知要展示认知 doc 和摘要；重点进展要给 PRD 和预计上线时间 | 周报正文“如何写周报” |
| 周报数据源 | DAU / 总 DNU 用数仓口径，业务 UA / 预装 / ASA DNU 用 AF / MI 看板，Organic 用数仓减业务 AF 口径 | 周报正文 |
| ROI 周期 | 周报 分析平台 为加权平均；本周 / 上周按日均窗口对比 | 周报正文 |
| ROI 预估偏差 | 需要按包体、端、媒体、模型和 D3/D7/D30/D60 节点拆高估 / 低估 | `forecast_bias_summary.csv` |
| ADX 判断 | 导流用户 ROI / eCPM 弱于信息流大盘时，不直接用看板均值下因果结论；需要单独排期做因果分析 | 周报正文 + `adx_traffic_summary.csv` |
| Push 判断 | DAU 和收入正向时仍要看总时长、ARPDAU、通知关闭率和 holdout 兜底 | 周报正文 + `push_experiment_summary.csv` |
| 风控核减 | 预期核减金额不等于立即核减动作；先技术沟通和补充协议，签订后按月核减 | 周报正文 + `risk_control_chargeback_summary.csv` |

## 使用边界

- 本 SOP 不是 verified SQL；所有经营判断都应回到 MI / CK / MaxCompute 复算。
- 图片抽取状态是 `reviewed_image_extracts`，不是 verified。
- 周报内的红线 / 达标线截图只作为本报告证据，不自动更新长期阈值政策。
- 不把“建议缩量 / 放量 / 核减”改写成自动动作；未授权时输出 `needs_decision`。
