# 发行增长双周会复盘 SOP

> 来源：`da_assets/raw/2026-06-10_发行增长双周会_docx.md`
> 状态：`draft`。本文从 docx 正文和 Word 表格抽取，图片仅归档未 OCR，所有图中数值需回源验证。

## 适用问题

用于回答和拆解：

- 发行增长双周会 / 周报里哪些产品 ROI 达标、跌破红线或接近达标线。
- DNU / DAU 下滑由 UA 管控、预装、organic、渠道结构还是产品因素驱动。
- 点位测试、素材冷启动、自投 campaign、ADX 互导、Push / 分享 / 承投实验当前处于什么阶段。
- 计划层级报表、ROI 模型、点位平台、素材平台、Push AB 等系统建设进度如何影响后续分析。

## 标准拆解流程

1. **先识别经营约束**
   - ROI 是否符合包体红线 / 达标线。
   - 是否有“跌破红线”“未达标”“近达标”“数据量小”等状态。
   - 所有 ROI 判断需回看 `knowledge/agent_knowledge/report_knowledge/PACKAGE_ROI_TARGET_THRESHOLDS.csv`，缺阈值时标 `missing_threshold`。

2. **再拆 DNU / DAU 变化**
   - 区分 UA、预装、organic、GP 下架、渠道关停、降价、风控拦截等原因。
   - 对关键市场单独拆，如 Game Top 美国。
   - 同时保留 all 与 paid_only 两版口径，避免 organic 混淆。

3. **抽取新计划孵化线索**
   - 点位测试：点位逻辑、上报方式、预算、ROI1/ROI7/分析平台、留存。
   - 素材：素材标签、批量合成、AIGC 变体、冷启通过率、渠道差异。
   - 自投：按产品 / 端 / campaign 生命周期看 ROI、CPI、国家 / Creative Set 结构。

4. **抽取增长产品实验**
   - Push：holdout、combo、LR、推全、关闭率、DAU、收入、时长、ARPU。
   - 分享：拉端链路、接入产品、提测时间。
   - 承投：登录 / 难度 / 广告参数等实验基建。
   - ADX：激活目标、ROI1、eCPM、人均时长、局数、样本命中率。

5. **抽取数据系统和平台能力**
   - 分析平台 固定观测周期查询能力：`分析平台_7d`、`分析平台_14d`、`分析平台_30d`。
   - campaign 治理模块：camp 列表、详情、趋势图、关联产品红绿看板。
   - 点位平台：点位字典、白盒化、模型预估点位。
   - 素材平台：素材洞察、标签、批量合成、AI 变体。

6. **输出待补数据**
   - 图片里的表格和图表原始数据。
   - 对应 SQL / 看板链接。
   - 生效日期、阈值 owner、动作 owner。
   - 后验数据：动作后 ROI、DNU、DAU、收入是否恢复。

## 本次报告抽出的复用口径

| 主题 | 口径 / 规则 | 来源 |
|---|---|---|
| ROI 周期偏移 | 需要固定观测周期 ROI，如 `分析平台_7d`、`分析平台_14d`、`分析平台_30d`，否则不同回收周期的数据不可比 | 双周会正文 |
| ROI 训练源 | ROI 模型训练从 AF 回收改为 SDK 回收，以优化 180-360 ROI 校准 | 双周会正文 |
| ROI720 | D720 ROI 通常高于 D360 ROI，示例产品 / 示例产品 / BC 多数汇总期增长约 8-16pp；后续需基于 ROI720 重新推导各端红线标准 | 双周会正文 + `roi720_summary.csv` |
| 点位模型风险 | 模型点位可能表现为留存好、ARPU 低、衰减快；S2S 重复上报会导致高估，收入字段未正确回传会影响学习 | 双周会正文 |
| ADX 分析限制 | ADX 用户 eCPM 低，人均时长和局数差异小；若实验命中样本仅约 10% 且样本差异大，看板直接对比无意义，需要因果分析 | 双周会正文 |
| Push 推全路径 | 5% 实验、单一实验、观测 7 天；数据正向后 LR 审批；保留 30 天以上反转实验，再 5%-10%-20%-全量灰度 | 双周会正文 |

## 使用边界

- 本 SOP 不是 verified SQL，不直接提供可复跑查询。
- 图片已做人工复核和结构化摘要；密集表、模糊红线 review 表仍只作为待补原始数据线索。
- 报告中“达标 / 跌破红线”的判断来自会议材料，正式治理判断仍需匹配结构化阈值表和最新数据。
