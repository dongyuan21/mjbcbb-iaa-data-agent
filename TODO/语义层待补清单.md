## 1. 仍缺：业务阈值与动作边界（需人拍板）

政策入口：`knowledge/agent_knowledge/policies/投放ROI治理政策.md`。Agent 只打标签/列候选/解释风险，**不输出最终投放动作**。

已有试运行：18 包体 × 平台 `trial_active`（`PACKAGE_ROI_TARGET_THRESHOLDS.csv`）；冷启动观察 ≥7 天；日均消耗 `< 300 USD` 只观察；头部接近红线 → `needs_decision`。

| 缺口 | 为什么还挂着 | Owner |
|---|---|---|
| 未覆盖包体的红线 / 达标线 | 18 包外只能标 `missing_threshold` | DA / UA |
| 风控黄线（禁止加量） | 无结构化阈值，只能 `needs_risk_owner` | 风控 / UA |
| ROI 下修 buffer、降预算幅度 | 跌破红线后的动作幅度未结构化 | UA |
| 放量 / 爬坡组合条件 | 冷启动天数、最低消耗、ROI/CPI/留存/LTV 倍率需 UA case；阈值由谁维护未定 | UA |
| 点位动作阈值 / 测试退出条件 | 仅有 draft 访谈提纲 | UA |
| 素材疲劳 / 新素材定义 | 前端 IPM/CPI 已有 vsql；疲劳窗口与 ROI 闭环未定 | DA / UA |

- 点位备选定义 + 至少一个端到端样例入库
- UA 冷启动/爬坡/疲劳 case 进入 `decision_cases` 或 policy
