# 报告证据结构

> 目标：让 Data Agent 在引用 DA 报告、截图、SQL 和复盘 case 时，能区分事实、判断、趋势和待补数据。

## 证据等级

| 等级 | 来源 | Agent 使用方式 |
|---|---|---|
| `verified` | 已执行 SQL、已校验表格、已复核数据导出 | 可作为默认事实引用。 |
| `confirmed` | 用户或业务 owner 明确确认的规则 | 可作为当前口径引用。 |
| `draft` | 初步整理、未复核 OCR、手工摘录 | 只能标注为候选。 |
| `raw` | 原始报告、截图、未处理导出 | 只作来源证据。 |
| `needs_source_data` | 图表无法可靠解析，需要补原始数据 | 只能输出待补数据。 |
| `needs_decision` | 口径冲突或动作阈值未拍板 | 不替业务决策。 |

## SQL 晋升等级

报告证据等级描述“这条 claim 能不能信”，SQL 晋升等级描述“这条 SQL 能不能被默认召回”。稳定 SQL 晋升规则以 `SQL晋升治理.md` 为准。

| promotion_status | 使用边界 |
|---|---|
| `raw` / `draft` | 不作为 SQL reference，只能说明来源或候选思路。 |
| `candidate_sql` | 已有 SQL，但未完成验证；不默认召回。 |
| `validated_sql` | 小窗口验证通过；可临时参考，不能当稳定口径。 |
| `verified_sql` | 可默认召回，仍需检查日期、分区和适用范围。 |
| `semantic_promoted` | 已进入语义层或稳定诊断路径，可支撑自然语言到 SQL。 |
| `needs_decision` | 口径未拍板，必须输出待决。 |
| `deprecated` / `superseded` | 不再默认引用，需指向替代 SQL 或说明废弃原因。 |

## 证据记录模板

```yaml
evidence_id: ""
claim: ""
claim_type: fact | trend | judgment | action | open_question

  title: ""
  path: ""
  source_type: dingtalk_adoc | dingtalk_html | docx_export | pdf_export | screenshot | sql_result | manual_note
  report_period: ""
  source_url: ""

  method: original_table | source_sql | ocr_table | manual_copy | chart_direction_only | archive_only
  extracted_at: "YYYY-MM-DD"
  reviewer: ""

  package_name: ""
  platform: ""
  channel: ""

  country: ""
  date_window: ""

    value: ""
    unit: ""

  - ""
```

## Claim 类型

| `claim_type` | 定义 | 示例 |
|---|---|---|
| `fact` | 可由表格、SQL 或 verified 数据支持的事实 | `kcolb tsalb GP 投放实际回收为 84%` |
| `trend` | 图表或时间序列支持的方向性变化 | `ROI360 观测周期拉长后有下修趋势` |
| `judgment` | 基于阈值和事实得到的判断 | `低于投放回收达标线` |
| `action` | 人做出的投放动作或建议 | `降预算、观察、上会讨论` |
| `open_question` | 缺数据或缺拍板的问题 | `业务目标与 DA 反推目标冲突时听哪个` |

## 引用规则

Agent 输出结论时应按以下顺序组织：

1. 事实：来自 `verified` / `confirmed` / 结构化表。
2. 判断：说明命中的阈值、规则和对象粒度。
3. 趋势：说明是否仅来自图表方向。
4. 风险：说明红线、达标线、数据量小、预测蓝底等限制。
5. 待补：列出无法从图片可靠提取或需要业务拍板的信息。

## 置信度约定

| `confidence` | 条件 |
|---|---|
| `high` | 可追溯到 SQL 结果、原始表格、已校验 CSV 或用户明确拍板。 |
| `medium` | 来自报告正文、简单图表趋势或已复核但未执行 SQL 的材料。 |
| `low` | 来自未校验 OCR、截图目测、单次手工摘录。 |

低置信度证据不得触发自动动作，只能生成待复核问题或候选清单。
