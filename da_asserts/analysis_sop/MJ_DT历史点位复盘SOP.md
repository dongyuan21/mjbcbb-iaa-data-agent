## 分析目标

识别哪些历史事件点位满足：

- 覆盖足够用户。
- 能区分高价值用户。
- 对 D30/D60/ROI360 有早期预测力。
- 可在不同地区、端、产品中稳定复用。
- 不会因为重叠、低渗透或高成本导致投放学习困难。

## Step 1：定义 cohort 和过滤

基础 cohort：

- 产品：MJ Android / MJ iOS / DT Android。
- 地区：GLOBAL、US、EU3、JP、KR、BR、ID。
- 时间：建议先小窗口验证，再扩展到完整周期。
- 排除预装或按业务要求排除特定媒体。

必须记录：

- 激活日期范围。
- 行为观察窗口。
- 收入成熟窗口。
- 是否剔除预装。

## Step 2：计算事件基础指标

每个事件至少计算：

| 指标 | 公式 / 说明 |
|---|---|
| 新增用户数 | cohort 新增用户 |
| 事件完成用户数 | 触发事件的 distinct 用户 |
| 事件次数 | event count |
| 渗透率 | 事件完成用户数 / 新增用户数 |
| 人均事件次数 | 事件次数 / 事件完成用户数 |

过滤建议：

- 有效点位：渗透率 >= 5%。
- 样本量门槛：新增用户中位数 >= 500 或按业务另定。

## Step 3：计算价值与质量指标

对触发事件用户计算：

| 指标 | 说明 |
|---|---|
| ARPU-D1 / D7 / D30 | 安装后窗口累计收入 / 触发用户 |
| 留存-D1 / D7 / D30 | 触发用户在对应天是否活跃 |
| 插屏 ECPM | 插屏收入 / 插屏展示 × 1000 |
| 激励 ECPM | 激励收入 / 激励展示 × 1000 |

早期信号判断：

- `ARPU-D1` 对 `ARPU-D30` 的 Spearman 相关性。
- `留存-D1` 对 `留存-D30` 的 Spearman 相关性。

## Step 4：事件类型分层

| 类型 | 解释 | 典型判断 |
|---|---|---|
| 回收点位 | 与收入 / eCPM 更强相关 | 高 ARPU，低渗透，适合高价值精投 |
| 事件点位 | 与行为 / 留存更强相关 | 中 ARPU，高渗透，适合大盘或中价值层 |
| 复合点位 | 行为 + 商业化组合 | 适合减少噪声，提高精准度 |
| 未知 | 命名或归因不清 | 先不作为正式推荐 |

## Step 5：Pareto 与权重敏感性

两种互补方法：

1. Pareto 前沿：在渗透率和 ARPU-D30 两维上没有被支配的事件。
2. 权重敏感性：在多套权重下均排名 Top25% 的事件为鲁棒点位。

推荐输出：

```text
鲁棒点位 = 四种权重方案均在 Top25%
优先复用 = 鲁棒点位 ∩ 可解释 ∩ 样本量足够 ∩ 无强重叠风险
```

## Step 6：可复用决策

| 决策 | 条件 |
|---|---|
| 优先复用 | 高价值、高稳定性、足够渗透、多权重鲁棒 |
| 小预算赛马 | 高价值但低渗透或波动高 |
| 对照观察 | 留存好但 ARPU 低，长线倍率可能好 |
| 淘汰 | 渗透低、重叠高、广告竞争力弱、无法放量 |

## 输出格式

每个产品 / 端 / 地区输出：

- Top 15 事件。
- 鲁棒点位清单。
- Pareto 前沿事件。
- 回收点位 vs 事件点位对比。
- 推荐复用 / 观察 / 淘汰结论。
- 需要重新打点或拉长窗口的事件。
