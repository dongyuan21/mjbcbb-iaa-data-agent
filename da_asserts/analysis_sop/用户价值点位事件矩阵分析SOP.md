## 分析目标

构建“用户价值 × 点位事件”的矩阵，回答：

1. 某个事件能覆盖多少用户？
2. 触发该事件的用户是否更高价值？
3. 该事件能否支撑投放算法学习和放量？
4. 该事件适合 UAC2.5、UAC3.0 还是只适合对照观察？
5. 事件适合哪个价值层：低 / 中 / 高？

## 输入

| 输入 | 说明 |
|---|---|
| cohort 用户 | 安装 / 激活用户，按产品、端、国家、渠道切片 |
| 事件行为 | 完成局数、复活局数、使用时长、广告展示、eCPM 等 |
| 价值指标 | D14 LTV、D30/D60/ROI360、ARPU、留存 |
| 投放指标 | CPI、CPA、消耗、量级、Goal |
| 实验维度 | UAC2.5 / UAC3.0、国家层级、事件阈值 |

## Step 1：事件候选池

按来源把候选事件分为：

| 类别 | 示例 | 作用 |
|---|---|---|
| 回收类事件 | Total025 / Total050 / Total100 | 高 ARPU / 低渗透，适合高价值圈选 |
| 关键特征事件 | AF83 / eCPM / 激励展示 | 高价值精投，成本可能较高 |
| 活跃类事件 | Game20 / Game27 / Game30 / 完成局数 / 使用时长 | 高留存、低成本、长线倍率观察 |

## Step 2：渗透率 × 价值二维评估

每个事件至少计算：

```text
触达率_全量 = 达到阈值用户数 / 全量新增用户数
触达率_活跃 = 达到阈值用户数 / 活跃用户数
高价值用户ARPU = 达到阈值且成熟用户的 D14 ARPU
普通参与用户ARPU = 活跃但未达阈值用户的 D14 ARPU
提升 = 高价值用户ARPU - 全量ARPU
```

判断：

- 高渗透 + 中价值：适合大盘或中价值层。
- 低渗透 + 高价值：适合高价值精投，但可能难放量。
- 高渗透 + 低价值：可能噪声大，不适合作优化目标。
- 低渗透 + 低价值：淘汰。

## Step 3：投放模式匹配

| 圈层 | 事件模式 | 投放模式 |
|---|---|---|
| 低价值圈层 | 高价值事件兜底 | UAC2.5 + 地区/事件深度限制 |
| 中价值圈层 | 浅层事件 + 高 Goal | UAC3.0 抗波动模式 |
| 高价值圈层 | 深层事件 + 中低 Goal | UAC3.0 高价值精投 |

## Step 4：稳定性判断

必须观察：

- D3 / D7 / D14 / D30 / D60 ROI 趋势。
- 分天 ROI360 波动。
- 事件重叠度。
- CPI 是否随放量拉高。
- 留存是否相对大盘稳定。

## Step 5：推荐 / 观察 / 淘汰

| 结论 | 条件 |
|---|---|
| 推荐 | 价值提升明显、触达率足够、CPI 可控、ROI 稳定 |
| 观察 | 留存好但 ARPU 低、短线 ROI 低但长线倍率好、样本不足 |
| 限制使用 | 高价值但低渗透或高 CPI，需要小预算/特定国家 |
| 淘汰 | 与其他事件重叠高、广告竞争力不足、无法支撑消耗 |

## 适合转 SQL 的问题

1. 每个事件的全量触达率和活跃触达率是多少？
2. 触发事件用户的 D14 ARPU / LTV 是否显著高于全量？
3. 事件之间的用户重叠率是多少？
4. 不同事件在 UAC2.5 / UAC3.0 下的 CPI / ROI360 表现如何？
5. Game20 / Game27 / Game30 哪个更适合 T0/T1 地区？
6. RevMix_D7 是否只适合 WW / 中低价值国家？
7. 高 eCPM 用户是否存在量级不足或成本过高问题？
