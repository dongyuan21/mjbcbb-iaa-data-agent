# DA 报告投喂规范

> 目标：把公司周报、DA 分析报告、钉钉文档和截图附件沉淀成 Data Agent 可检索、可追溯、不会误读图片的知识资产。

## 适用范围

本规范适用于：

- 公司周报、DA 周报、专项分析报告。
- 钉钉在线文档、HTML / PDF / Word 导出件。
- 报告内图片、表格截图、统计图、热力图。
- 从报告抽出的 SQL、图表数据、SOP、决策 case。

## 基本原则

| 原则 | Agent 行为 |
|---|---|
| 原始报告只作证据 | `da_assets/raw/` 中的材料默认不是最终事实。 |
| 结构化数据优先 | 可拿 Excel / CSV / SQL 结果时，不从截图反推数值。 |
| 图片内容需显式标注 | 钉钉 MCP 看到图片链接不等于读到了图片内容。 |
| OCR 只作中间产物 | OCR 表格必须人工或二次校验后才能升为可引用事实。 |
| 图表结论分层 | 数值、趋势、判断、动作建议必须区分来源和置信度。 |

## 推荐目录结构

每份报告建议按主题放成一个 raw 资产，复杂报告可配套附件目录：

```text
da_assets/raw/
  YYYY-MM-DD_主题_来源.md
  YYYY-MM-DD_主题_attachments/
    image_001.png
    image_002.png
    table_001.csv
    chart_001_data.csv
    metadata.yaml
```

`metadata.yaml` 建议包含：

```yaml
source_title: ""
source_type: dingtalk_adoc | dingtalk_html | docx_export | pdf_export | manual_copy | user_screenshot
source_url: ""
report_period: ""
owner: ""
ingested_at: "YYYY-MM-DD"
mcp_read_status: text_and_tables_readable | image_links_seen_but_not_ocr_verified | not_applicable
image_status: no_image | images_archived | table_images_ocr_pending | table_images_ocr_verified | charts_need_source_data | dense_images_archive_only
structured_outputs:
  - path: ""
    status: draft | verified | needs_review
```

## 进入知识库的分流规则

| 材料 | 放置位置 | 默认可信度 | 进入稳定召回的条件 |
|---|---|---|---|
| 原始报告正文 | `da_assets/raw/` | 低 | 抽取成 SOP / SQL / case 后再引用。 |
| 原始截图 | `da_assets/raw/*_attachments/` | 低 | 只作证据，不直接参与数值判断。 |
| OCR 表格 | `da_assets/raw/*_attachments/` | 中低 | 人工校验后标 `verified`。 |
| 图表背后数据 | `da_assets/raw/*_attachments/` 或 `raw_exports/` | 中 | 确认来源和时间窗口后可升为 SOP / case 证据。 |
| 可复用 SQL | `da_assets/verified_sql/` | 高 | 必须带日期/分区过滤并执行验证。 |
| 分析流程 | `da_assets/analysis_sop/` | 中 | 明确输入、口径、输出和不能自动拍板的边界。 |
| 决策复盘 | `da_assets/decision_cases/` | 视状态而定 | 需要记录动作、owner、后验结果。 |

## 报告抽取最小字段

从周报或 DA 报告沉淀资产时，至少记录：

| 字段 | 说明 |
|---|---|
| `source_title` | 原报告标题。 |
| `source_type` | 钉钉文档、HTML、Word / PDF 导出、手工复制、用户截图等。 |
| `report_period` | 报告覆盖周期。 |
| `business_question` | 报告回答的问题。 |
| `metric_scope` | 指标范围，如 ROI360、LTV、留存、CPI、消耗。 |
| `dimensions` | 包、平台、渠道、campaign、国家、观察周期等维度。 |
| `data_window` | SQL 或图表使用的数据窗口。 |
| `image_dependency` | 是否依赖图片中的表格或图。 |
| `extraction_method` | 原表、SQL、OCR、人工录入、只读图归档。 |
| `confidence` | `high` / `medium` / `low`。 |

## Agent 输出边界

Agent 可以基于已结构化材料输出：

- 报告事实摘要。
- 指标、维度、时间窗口和来源对齐。
- 跌破红线、低于达标线、数据量小等候选判断。
- 缺失原始数据、图片无法可靠解析、需要 DA 补表的问题清单。

Agent 不应输出：

- 从热力图或复杂折线图截图中反推出的精确数值。
- 把未校验 OCR 当作 verified 事实。
- 把 `raw/` 中单份报告结论升级成长期业务规则。
- 在阈值冲突时替业务决定以哪条线为准。
