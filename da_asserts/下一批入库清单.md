# DA 资产下一批入库清单

> 目标：把 DA 报告、钉钉 docs、HTML、SQL 转成可被 agent 复用的 verified SQL、analysis SOP 和 decision case。

## 你可以提供什么

| 类型 | 放入位置 | 处理方式 |
|---|---|---|
| 钉钉 docs 链接 | `raw/` 索引 | 先读文本和表格；图片需单独视觉/OCR 复核 |
| HTML 报告 | `raw/` | 抽取正文、表格、结论和图表说明 |
| DA 原始 SQL | `raw/` 或 `verified_sql/` | 先标 `copied_unverified`，跑通后改 `verified` |
| 周报 / 复盘结论 | `analysis_sop/` / `decision_cases/` | 抽成 SOP 或 case |
| 人工口述规则 | `analysis_sop/` draft | 必须标来源和审核状态 |

## 优先收集的 5 类材料

1. **日复盘报告**：消耗、ROI、留存、收入、异常归因。
2. **campaign 复盘 SQL**：能判断放量/降预算/停投。
3. **SDK vs AF 回收对比 SQL**：用于解释 `revenue_source=sdk/af`。
4. **预测 ROI 评估报告**：用于理解 forecast 可信度。
5. **素材复盘报告**：CTR/IPM/CPI/ROAS 与素材标签。

## 入库状态

| status | 可被 agent 默认召回 | 说明 |
|---|---|---|
| `raw` | 否 | 原始材料，仅作证据 |
| `draft` | 否 | 已抽取但未审核 |
| `copied_unverified` | 否 | SQL 已复制但未执行 |
| `verified` | 是 | SQL 已带过滤执行，输出经过 review |
| `promoted` | 是 | 已进入正式知识库 |
| `rejected` | 否 | 过时、冲突或低质量 |
